# Changes

## 0.4.1 — 2026-10-11

Adds cross-platform CI, a container recipe, packaging metadata,
offline CLI smoke checks and validation edge-case tests. Numerical kernels and
bundled experimental inputs are unchanged from published 0.4.0. The 12-job
Ubuntu/macOS/Windows by Python 3.9–3.12 matrix and Linux container job passed
on the engineering candidate (commit 4c8c8c2). Stable-version CI must also
pass before the release tag is published. See CI_VALIDATION.json and Actions.
README now states the limitation of adjustment for noisy measured controls.
This release is not yet published to PyPI or assigned a new Zenodo DOI.
